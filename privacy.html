Who operates this application

NPI Review System is operated by Netpromotion Invest Kft., Budapest, Hungary. Contact: zsomb.petnehazi@gmail.com.

What the application does

The application connects to Google Business Profile on behalf of a user who manages one or more business locations. With that user's explicit authorisation it reads the reviews posted to those locations, prepares draft replies for human review, and, where the user has enabled it, posts approved replies.

What data is accessed and stored

  • Public review content for authorised locations: rating, review text, reviewer display name, and posting date, as published on Google.
  • Reply drafts and posted replies created through the application.
  • Location identifiers and review counts needed to detect new reviews.
  • An authorisation token issued by Google, stored encrypted and used only to perform the actions above.

How Google user data is used

Google user data obtained through the Google Business Profile API is used solely to provide the functions described above to the authorising user. It is not sold, not used for advertising, and not shared with third parties except the infrastructure providers that host the application.

Retention and deletion

Data is retained while the location remains connected. A user may revoke the application's access at any time from their Google account permissions page, after which no further data is read. Stored data for a disconnected location is deleted on request to the contact address above.
